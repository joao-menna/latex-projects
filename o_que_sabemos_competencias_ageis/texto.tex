\section{Kanban}

Kanban é um método de gestão visual que usa um quadro com colunas para representar as etapas de um processo.
As tarefas são representadas por cartões que se movem por essas colunas, permitindo que a equipe visualize o fluxo
de trabalho e o progresso de cada atividade. A essência do Kanban está em limitar a quantidade de trabalho em andamento
para evitar sobrecarga, aumentar o foco da equipe e garantir um fluxo de trabalho contínuo e eficiente. Ele facilita
a comunicação e a identificação de gargalos, pois todos podem ver o status das tarefas em tempo real, tornando a
gestão do projeto mais ágil e colaborativa.



\section{Ferramenta de teste unitário}

Os testes unitários verificam várias partes de uma aplicação, como funções, métodos ou classes, para garantir que elas
funcionem de forma correta. Atualmente, existem vários tipos de ferramentas para testes, geralmente, divididas por linguagem.
São algumas delas: JUnit, Jest, pytest e NUnit.



\section{Docker}

Docker é uma plataforma de código aberto que facilita a criação e execução de ambientes isolados chamados containers.
Ele surgiu como solução para eliminar problemas de compatibilidade entre ambientes de desenvolvimento, teste e produção,
garantindo que a aplicação funcione de maneira uniforme independentemente de onde for executada.
O Docker utiliza o conceito de \textit{containerização}, que é uma forma de virtualização em nível de sistema operacional.
Diferente das máquinas virtuais tradicionais, onde cada instância possui seu próprio sistema operacional completo, os containers
compartilham o mesmo kernel do sistema hospedeiro, tornando-os mais leves e rápidos para iniciar.



\section{Kubernetes}

Kubernetes, também conhecido como \textbf{K8s}, é uma plataforma de código aberto desenvolvida inicialmente pelo Google para
automatizar a implantação, o escalonamento e o gerenciamento de aplicações em containers. É amplamente utilizado com o Docker,
embora suporte outros runtimes de containers. O Kubernetes atua como orquestrador de containers, garantindo que as aplicações
sejam executadas conforme o esperado em um cluster de máquinas. Seu principal objetivo é simplificar a execução de sistemas
distribuídos.



\section{Apache Kafka}

O Apache Kafka é uma plataforma de processamento de streaming desenvolvida pelo LinkedIn e foi posteriormente doada à
Apache Software Foundation. Foi projetado para lidar com a ingestão e processamento de dados de streaming em tempo real
com alta taxa de transferência e baixa latência. O Kafka é amplamente usado para criar pipelines de dados e aplicações
se adaptam aos fluxos de dados. Ele combina mensagens, armazenamento e processamento de fluxo para permitir o armazenamento
e a análise de dados.
